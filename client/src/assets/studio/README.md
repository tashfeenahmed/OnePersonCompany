`digital-studio.webp` is original artwork generated with the built-in image-generation tool, using the user's supplied collage illustration as an aesthetic reference. It is delivered as a compressed 1440 × 480 static WebP with an alpha channel; no animation library or canvas is needed.

## Generation prompt

Use case: stylized-concept. Asset type: a panoramic header illustration for a digital content studio where social posts and videos are created. Input image: aesthetic reference only. Create a fresh original scene using the reference's playful flat editorial collage aesthetic: bold simple shapes, vibrant cyan, hot pink, orange, red, emerald and deep purple, crisp black outlines, expressive geometric characters and overlapping creative objects. Subject: three playful creators collaborating around a video editing monitor, a film camera, a clapperboard, a portrait video card with a play symbol, square social post canvases, a pen tool and color palette. Compose it as one tightly integrated horizontal collage with expressive hands and inventive silhouettes. Pure black background. Extra-wide 3:1 landscape format, composition fills most of the width, all important objects remain fully inside the frame, small black breathing room around the edges. Shapes should be legible at a compact 200px displayed height. Flat vector-like illustration with solid colors, no gradients, no 3D, no realistic textures, no glow. No written words, no letters, no file extension labels, no logos, no watermark. This is an illustration asset, not a webpage screenshot. Follow the attached reference aesthetic closely while making the subject clearly about content creation.

## Transparent background

At the user’s request, the surrounding black background was removed directly from the original artwork using local image processing. The original colors and interior black details are retained. The header container has no background fill, so the asset works in both themes.
